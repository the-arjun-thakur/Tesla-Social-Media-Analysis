## 📊 Project Overview

The **Tesla Social Media Analysis Dashboard** is an interactive data analytics project built using **Microsoft Excel**.
This dashboard analyzes Tesla’s social media performance across multiple platforms and provides insights into engagement, follower growth, advertising spend, and content performance.

The goal of this project is to transform raw social media data into **meaningful visual insights** that help understand audience engagement and marketing effectiveness.

---

## 🎯 Objectives

* Analyze engagement across social media platforms.
* Evaluate the performance of different content types.
* Track follower growth trends.
* Understand the relationship between **ad spend and engagement**.
* Build an **interactive dashboard for quick decision-making**.

---

## 📌 Dashboard Features

* **Platform Engagement Analysis**
  Compare engagement across Facebook, Instagram, Twitter, and YouTube.

* **Content Performance Insights**
  Analyze engagement for different content types:

  * Video
  * Image
  * Reel
  * Story
  * Carousel
  * Text

* **Follower Growth Tracking**
  Monitor follower trends and growth rate across platforms.

* **Ad Spend Analysis**
  Understand how advertising investment impacts engagement and growth.

* **Interactive Filters (Slicers)**
  Users can filter data by:

  * Platform
  * Campaign Name
  * Ad Spend

* **Key Performance Indicators (KPIs)**

  * Total Posts
  * Number of Platforms
  * Marketing Budget
  * Engagement Score

---

## 📈 Key Insights

* Instagram contributes the **highest engagement share** among platforms.
* **Video and Reel content generate stronger audience interaction.**
* Advertising spend impacts follower growth trends across platforms.
* Data visualization helps identify **effective marketing strategies**.
